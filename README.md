# CondiRico Frontend Prototype

Construye un prototipo frontend responsive de alta fidelidad para un ecommerce llamado "CondiRico", inspirado en la imagen de referencia adjunta. Replica su estructura y estética: fondo blanco, verde oscuro principal, naranja como acento, tipografía moderna tipo Inter/SF Pro, diseño premium/minimalista. Incluye: header con logo/navegación/buscador/usuario/carrito; hero con "Todo lo que necesitas en un solo lugar", CTA Comprar Ahora y composición de supermercado; categorías (Alimentos Sellados, Productos de Primera Necesidad, Limpieza del Hogar, Útiles del Hogar); productos destacados en carrusel con imagen, nombre, precio, favoritos y Agregar al carrito; banner de ofertas; sección de 5 beneficios; banner verde; testimonios; newsletter; footer. Usa datos mock. Añade hover, microinteracciones, responsive y funcionalidad básica para búsqueda, favoritos, carrito y carruseles. No backend ni pagos todavía. Mantén la composición muy cercana a la referencia y mejora su responsive y legibilidad.
